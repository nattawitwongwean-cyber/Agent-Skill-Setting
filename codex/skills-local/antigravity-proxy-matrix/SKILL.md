# Antigravity Proxy Matrix

Use only verified matrix/probe evidence.

## Rules

- Say `usable X/N`, not `all models usable`, unless all passed probe.
- Do not run expensive full probes unless user asks.
- Distinguish listed, usable_now, quota_exhausted, broken, and manual_until_retested.
- Never call Gemini CLI the Hermes brain.
