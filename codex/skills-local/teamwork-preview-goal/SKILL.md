# Teamwork Preview Goal

Before large work, split it into small cells with clear objective, scope, owner, output, and verification.

## Micro-plan Fields

- objective
- scope
- inputs
- output
- allowed changes
- verification
- stop conditions

Use `subagent-driven-development` when a cell can be delegated independently.
