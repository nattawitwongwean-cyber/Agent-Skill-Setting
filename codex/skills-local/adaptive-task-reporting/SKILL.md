# Adaptive Task Reporting

Report only what is supported by evidence.

## Status Vocabulary

- `verified_done`: acceptance criteria met with fresh evidence.
- `verified_partial`: some criteria met, but something remains unverified or incomplete.
- `blocked`: cannot proceed without missing access/input/external state.
- `not_verified`: not checked with fresh evidence.

## Footer Minimum

Include model/route if known, skills used, verification evidence, changed files, remaining work, and blockers. Never say done if browser/test/deploy evidence says partial.
